# ParcelCost

ParcelCost is a small C++ console program created as part of my Programming III coursework.

The program calculates parcel shipping costs based on the parcel weight, shipping speed, and whether the destination is on an island.

## Features

- Reads parcel weight from the user
- Supports Standard, Express, and Overnight shipping
- Calculates shipping cost based on weight
- Applies a shipping speed multiplier
- Adds an island surcharge when required
- Calculates the cost per kilogram
- Prints a formatted shipping receipt

## C++ Concepts Practiced

- Variables and data types
- `std::cin` and `std::cout`
- `if / else if / else`
- `switch / case / break`
- Comparison operators
- Arithmetic operations
- `std::string`

## Example

For a 4 kg parcel using Express shipping to an island:

- Base cost: 10 CNY
- Express multiplier: 1.5
- Island surcharge: 5 CNY
- Total cost: 20 CNY
