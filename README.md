## Featured Lab: ParcelCost

`ParcelCost` is a small C++ console application developed as part of my Programming III coursework.

The program calculates shipping costs based on parcel weight, shipping speed, and destination type.

### Concepts Used

- Variables and data types
- User input and output
- `if / else if / else`
- `switch / case / break`
- Comparison operators
- Arithmetic operations
- `std::string`

See [`labs/parcel-cost`](labs/parcel-cost) for the source code and project documentation.
